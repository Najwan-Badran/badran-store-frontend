## Unfixed Bugs Found

1. **Admin reporting and admin order list endpoints return 500 on PostgreSQL.**
   - Affected: `/api/v1/admin/dashboard/metrics`, `/api/v1/admin/reports/sales`, `/api/v1/admin/reports/sales/chart`, `/api/v1/admin/orders`.
   - Root cause: optional nullable date/status query parameters in repository queries are written as `:param IS NULL OR ...`, which PostgreSQL cannot type reliably for prepared null parameters.
   - Recommended fix: replace these queries with Criteria/Specification-based dynamic predicates, separate no-filter and filtered repository methods, or typed native SQL casts.

2. **Admin desktop header overlaps language control.**
   - Affected: admin-authenticated desktop header.
   - Root cause: desktop navigation width overlaps account controls; `Admin Dashboard` nav item intercepts pointer events over the language button.
   - Recommended fix: constrain nav flex width, allow nav scrolling/clipping before account controls, or collapse earlier for admin users.

3. **`/api/v1/auth/me` without `X-User-Id` returns 500.**
   - Root cause: `MissingRequestHeaderException` is not mapped to a 400 response.
   - Recommended fix: add `GlobalExceptionHandler` coverage or derive the user id from the authenticated principal.

4. **Local Flyway state blocks normal backend startup.**
   - Root cause: current DB migration history checksum drift.
   - Recommended fix: repair/recreate local DB or reconcile migration history.
